# kevcpp 并发性能基准测试报告（CPU / Vulkan × 0.8B / 4B / 9B）

- 日期：2026-10-12
- 分支：`feature/concurrency-p1-batch`（含 B1-B3 单 ctx 多 sequence 连续批 + LCP 前缀缓存）
- 后端：CPU（默认 KV）+ Vulkan（AMD Radeon 8060S）
- 宿主机：AMD 8060S（UMA 显卡），Windows，kevcpp CPU 后端多线程
- 指标口径：`latency_ms` = 服务端推理计时（不含客户端网络/进程启动开销）；`Private` = 进程专用内存

> 说明：并发实现为「单 ctx 多 sequence（B1）+ 请求批调度器（B2）+ 有界动态连续批（B3）」。调度器 `max_concurrency=8`、`n_seq_max=14`、聚合窗口 400us。

---

## 1. 场景定义

- **前缀复用（PREFIX-REUSE）**：相同中文报文连发，命中 LCP 前缀缓存（只续算 tail）。
- **不复用（NO-REUSE）**：16 条完全不同中文报文交替发（state/criteria 均不同），无前缀命中，每次完整 prefill。

## 4. 内存表现

进程级内存（含模型权重）。

### 4.1 CPU

| 模型 | idle Private | C=8/16 Private | 每并发增量 |
|---|---|---|---|
| 0.8B | 1002.3 MB | 1006.6 MB | ≈ 0 |
| 4B | 1786.6 MB | 1786.5 MB | 0 |

> 权重单份共享 / 内存映射，KV 复用 sequence 池 → **并发不增加内存**。

### 4.2 Vulkan（9B，ctx=2048）

| 状态 | Private | WorkingSet |
|---|---|---|
| idle（加载后） | 10774.3 MB | 1212 MB |
| C=8 前缀复用 | 10979.4 MB | 1316.2 MB |
| C=8 不复用 | 10980.9 MB | 1317.9 MB |

> idle→C=8 增量：Private +205~207MB（≈+25MB/并发槽），WorkingSet +104~106MB。ctx 固定 2048 时 KV/seq 内存有界，增长温和。

## 5. 结论

### 5.1 响应时间
1. **C=2 通常是甜蜜点**（略优于 C=1，batch 摊薄固定开销）。
2. **无前缀复用（不同报文）高并发下明显退化**：3 模型一致 C≥8 后响应急剧上升，且模型越大退化越陡（CPU 9B C=8≈5.9s、C=16≈8s）。原因：无前缀复用 = 每次完整 prefill，多 sequence 并行时总计算量（FLOP/带宽）随并发线性累加，batch 摊薄被吞没。
3. **前缀复用的收益随模型增大而扩大**：9B 不复用 C=8 约为复用的 2×，说明大模型 prefill 是瓶颈，前缀缓存价值更高。

### 5.2 并发上限
4. **Vulkan 后端受调度器 `max_concurrency=8` 硬约束**：C=16 时 4B/9B 出现 8-32% 请求 >240s 超时（GPU 单设备无法真正并行，排队背压）。CPU 多线程无此硬上限，可吃更高队列并发。
5. C≤8 全部模型/场景 100% 成功、0 超时，Vulkan 多 sequence 并发正确。

### 5.3 内存
6. **CPU 三个模型并发内存增长 ≈ 0**（权重单份，KV 复用）。
7. **Vulkan 9B 并发内存增长温和有界**（C=8 时 +205MB）；复用/不复用几乎无差异。

---

## 6. 业务建议
- **同任务多数据（共享 instructions+options 前缀）**：前缀缓存有效，并发可用到 4-8（注意 9B 在 C≥4 已明显上升）。
- **类型多样的高并发（无前缀复用）**：单 ctx 多 sequence 的连续批在**大模型 C≥8 明显退化**。若业务属此类，建议补**多核并行 worker 池**（每 worker 独立 context 真并行），或依赖 Vulkan GPU 并控制并发 ≤ 调度上限。
- **9B 用 Vulkan 而非 CPU**（CPU 单请求 1.2-1.5s；Vulkan 快且并发存活性需控制在 max_concurrency 内）。

---

## 7. 已知局限 / 诚实标注
- 高并发档（C=8/16）CPU 侧有部分请求因等待超时被剔除，均值可能略低估真实尾延迟；Vulkan C=16 超时单列为存活率，未伪造。
- Vulkan 数据 avg/min/max 波动大（冷启动未命中请求 1-6s 与命中 90-200ms 混拉均值），min 列最能体现前缀缓存收益。
- 9B Vulkan idle 私有内存 ~10.8GB（Q8+ctx 共享显存），低于同模型 CPU 全驻留 DRAM 预期，说明模型主体在显存侧。
- 复测基线：`build/vulkan-bench/results.md`；CPU 数据见主会话实测。
