## 4. 结论

### 4.1 最优模型
- **qwen3.6-35B-A3B-UD = 68.2%，五模型最高**，反超 9B（67.1%）。
- 打破了 qwen3.5 时代"越大越不准"：q3.5-35B 是 64.7%（反降），q3.6-35B 是 68.2%（反升）。

### 4.2 qwen3.6 相对 qwen3.5-35B 的大幅纠正
- 币种识别 1→4、日期先后 1→4、反讽讽刺 2→4、距离阈值 3→5、事件分类 4→5 —— 集中在语义 / 货币 / 日期 / 反讽类。

### 4.3 qwen3.6 的新回退（与 9B / q3.5 互补）
- 否定/反义 5→2、金额阈值 5→2、持股 3→2 —— 集中在"取反 / 数值累加 / 持股折算"类。
- 即无单模型全胜，模型间强弱互补。

### 4.4 通道级局限（跨模型共性，非 bug）
- **score 情绪判别的中档塌缩**：除 q3.5(n=60%) 外各模型稳定 40%，正确答案不在中间档时判中档 → logits 通道对"评分级别 token"无内建判断力。
- **多候选显著更难**：4 候选各模型约 14-36%，q3.6 首次到 43%(6/14)。
- **小模型缺负样例判别**：noul 上 0.8B always-yes、4B near-always-yes；9B 最平衡(TP18/TN15)；35B-q3.5 极端保守(FP0)、35B-q3.6 回摆偏"是"(TP21/TN10)。

### 4.5 性能参考（Vulkan，判别通道）
- 35B-q3.6 平均延迟 ~256ms，比 35B-q3.5(~421ms) 约低 39%。（跨构建数据，仅作趋势参考。）
